# Data Understanding

## Definition

Data Understanding is the process of exploring and analyzing a dataset before data cleaning and model building.

---

# Purpose

The goal of Data Understanding is to understand the structure, quality, and characteristics of the dataset.

---

# Main Tasks

## Dataset Shape

Determine the number of rows and columns.

---

## Column Names

Identify all available features.

---

## Data Types

Check the data type of every column.

Examples:

- Integer
- Float
- Object
- Boolean
- Datetime

---

## Feature Types

### Numerical Features

Contain numeric values.

Examples:

- Age
- Salary
- Price

### Categorical Features

Contain categories or labels.

Examples:

- Gender
- City
- Department

---

## Statistical Summary

Analyze numerical data using:

- Count
- Mean
- Standard Deviation
- Minimum
- Maximum
- Quartiles

---

## Initial Data Visualization

Common visualizations include:

- Histogram
- Scatter Plot
- Pair Plot

---

# Data Understanding Workflow

```text
Load Dataset
      ↓
Check Shape
      ↓
View Columns
      ↓
Check Data Types
      ↓
Identify Feature Types
      ↓
Generate Statistical Summary
      ↓
Visualize Data
```

---

# Key Points

- Data Understanding is the first step of Data Preprocessing.
- It helps identify data quality issues.
- Understanding the dataset improves later preprocessing decisions.
- Every Machine Learning project should begin with data exploration.
