# Deployment Strategies

## Definition

Deployment is the process of making a trained Machine Learning model available for real-world use.

---

# Purpose

Deployment allows users and applications to use the trained Machine Learning model to make predictions.

---

# Why Deployment is Important

- Makes the model available to users.
- Delivers business value.
- Enables real-world predictions.
- Automates decision-making.

---

# Common Deployment Methods

## Web Applications

Examples:

- Streamlit
- Flask
- Django

---

## Mobile Applications

Examples:

- Android Apps
- iOS Apps

---

## APIs

The model is exposed as an API so other applications can request predictions.

---

## Cloud Deployment

Examples:

- AWS
- Microsoft Azure
- Google Cloud Platform

---

# Deployment Workflow

```text
Train Model
      ↓
Evaluate Model
      ↓
Optimize Model
      ↓
Save Model
      ↓
Deploy
      ↓
Users Make Predictions
```

---

# Model Monitoring

After deployment, the model should be monitored regularly to ensure consistent performance.

Monitoring includes:

- Prediction quality
- Accuracy
- Data changes
- Model retraining when required

---

# Key Points

- Deployment is the final step of the Machine Learning workflow.
- A deployed model can be accessed by real users.
- Deployment can be done through web apps, APIs, mobile apps, or cloud platforms.
- Monitoring is essential after deployment.
