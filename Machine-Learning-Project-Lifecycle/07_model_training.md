# Model Training

## Definition

Model Training is the process of teaching a Machine Learning algorithm using training data so that it can learn patterns and relationships.

---

# Purpose of Model Training

The objective of model training is to enable the algorithm to make accurate predictions on unseen data.

---

# Dataset Split

A dataset is generally divided into:

- Training Data
- Testing Data

## Training Data

Used to teach the Machine Learning model.

Typical split:

- 70%–80%

## Testing Data

Used to evaluate the trained model.

Typical split:

- 20%–30%

---

# Model Training Workflow

```text
Training Data
      ↓
Find Patterns
      ↓
Learn Relationships
      ↓
Adjust Parameters
      ↓
Trained Model
```

---

# Parameters

Parameters are internal values learned automatically during training.

Examples:

- Linear Regression coefficients
- Decision Tree split rules

---

# Goal of Training

- Learn patterns from data.
- Minimize prediction error.
- Build a model that generalizes well to new data.

---

# Example

Training a House Price Prediction model using:

- Area
- Bedrooms
- Bathrooms

Target:

- House Price

---

# Key Points

- Model Training starts after Model Selection.
- Only training data is used for learning.
- Parameters are learned automatically.
- A trained model is evaluated using testing data.
- Better training data usually leads to better model performance.
