# Problem Definition

## Definition

Problem Definition is the first step in the Machine Learning project lifecycle. It defines the problem that needs to be solved, the project objective, and the expected outcome.

---

# Why Problem Definition is Important

A clear problem definition helps:

- Select the correct dataset.
- Choose the appropriate Machine Learning algorithm.
- Define the target variable.
- Measure project success.
- Avoid wasting time and resources.

---

# Components of Problem Definition

## Project Objective

The main goal of the Machine Learning project.

**Examples**

- Predict house prices.
- Detect spam emails.
- Predict customer churn.

---

## Input Features

The input variables provided to the model.

**Examples**

- Age
- Salary
- Experience
- Location

---

## Target Variable

The output that the model predicts.

**Examples**

- House Price
- Loan Approval
- Disease Status

---

## Business Goal

The business value achieved by solving the problem.

**Examples**

- Increase sales
- Reduce fraud
- Improve customer satisfaction
- Detect diseases early

---

# Characteristics of a Good Problem Statement

- Clear
- Specific
- Measurable
- Data Available
- Solvable using Machine Learning
