# Data Collection

## Definition

Data Collection is the process of gathering relevant data required to train and evaluate a Machine Learning model.

---

# Why Data Collection is Important

High-quality data is essential for building accurate and reliable Machine Learning models.

Poor-quality data leads to poor model performance.

---

# Sources of Data

## Internal Data

Data collected within an organization.

**Examples**

- Customer records
- Sales data
- Employee database
- Transaction history

---

## External Data

Data collected from outside sources.

**Examples**

- Kaggle
- Government datasets
- APIs
- Public datasets

---

# Types of Data

## Structured Data

Data stored in rows and columns.

**Examples**

- Excel files
- SQL databases

---

## Unstructured Data

Data without a predefined structure.

**Examples**

- Images
- Videos
- Audio
- Documents

---

## Semi-Structured Data

Data that has some organizational structure but is not stored in relational tables.

**Examples**

- JSON
- XML

---

# Primary Data

Data collected directly by the organization.

**Examples**

- Surveys
- Interviews
- Sensors
- Experiments

---

# Secondary Data

Existing data collected by other sources.

**Examples**

- Research papers
- Government reports
- Kaggle datasets

---

# Characteristics of a Good Dataset

- Relevant
- Accurate
- Complete
- Updated
- Consistent
- Minimal missing values
- Duplicate-free

---

# Common Data Quality Problems

- Missing values
- Duplicate records
- Outliers
- Incorrect values
- Inconsistent formatting

---

# Workflow

```text
Problem Definition
        ↓
Data Collection
        ↓
Data Quality Check
        ↓
Data Preprocessing
```

---

# Key Points

- Data Collection is the second step in the Machine Learning lifecycle.
- High-quality data improves model performance.
- Data can be collected from internal and external sources.
- Data may be structured, unstructured, or semi-structured.
- Data quality should always be checked before preprocessing.
