# Machine Learning Introduction

## Definition

Machine Learning is a branch of Artificial Intelligence in which computers learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every situation.

## Basic Idea

In traditional programming, developers provide data and predefined rules to generate an output.

In Machine Learning, the system is provided with data and examples. It learns the underlying patterns and creates a model that can make predictions on new data.

## Machine Learning Workflow

1. Collect data.
2. Prepare the data.
3. Train a Machine Learning model.
4. Provide new data to the trained model.
5. Generate a prediction or decision.

## Example: Spam Email Detection

A Machine Learning model is trained using previously labeled emails:

- Spam emails
- Normal emails

The model learns patterns such as frequently used words, links, and email structure.

After training, the model can classify a new email as:

- Spam
- Normal
