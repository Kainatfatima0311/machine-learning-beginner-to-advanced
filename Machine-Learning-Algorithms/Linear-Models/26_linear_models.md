# Linear Models — Linear Regression

## Introduction

Linear Regression is a Supervised Machine Learning algorithm used to predict a continuous numerical target.

Examples include:

- House Price Prediction
- Salary Prediction
- Sales Prediction
- Temperature Prediction

Linear Regression learns the relationship between input features and a numerical target.

---

# 1. Linear Regression

## Definition

Linear Regression finds a linear relationship between input features and a continuous target variable.

Basic flow:

```text
Input Features
      ↓
Linear Regression
      ↓
Numerical Prediction
```

Example:

```text
House Area
    ↓
House Price
```

---

# 2. Best-Fit Line

Linear Regression attempts to find a straight line that best represents the relationship between the input and target.

Example:

```text
Study Hours → Marks
```

Real observations may not lie exactly on the line.

The goal is to find a line that minimizes prediction errors across the training data.

---

# 3. Linear Regression Equation

The basic equation for Simple Linear Regression is:

```text
y = mx + b
```

Where:

```text
y = Predicted target
x = Input feature
m = Slope / Coefficient
b = Intercept
```

Example:

```text
Salary = 10,000 × Experience + 30,000
```

---

# 4. Slope / Coefficient

## Definition

The slope represents how much the predicted target changes when the input feature increases by one unit.

In:

```text
y = mx + b
```

`m` represents the slope.

Example:

```text
Salary = 10,000 × Experience + 30,000
```

Here:

```text
m = 10,000
```

This means that according to the fitted model, one additional unit of experience is associated with an increase of 10,000 in the predicted salary.

---

# 5. Intercept

## Definition

The intercept represents the predicted value of `y` when `x = 0`.

In:

```text
y = mx + b
```

`b` represents the intercept.

Example:

```text
Salary = 10,000 × Experience + 30,000
```

Here:

```text
b = 30,000
```

When:

```text
Experience = 0
```

the model predicts:

```text
Salary = 30,000
```

The intercept may not always have a meaningful real-world interpretation.

---

# 6. Making Predictions

Suppose the learned relationship is:

```text
Salary = 10,000 × Experience + 30,000
```

For:

```text
Experience = 5
```

Prediction:

```text
Salary = 10,000 × 5 + 30,000

Salary = 80,000
```

Therefore:

```text
Predicted Salary = 80,000
```

---

# 7. Actual vs Predicted Values

The actual value is the real observed target.

The predicted value is the output generated by the model.

Example:

```text
Actual Salary    = 85,000
Predicted Salary = 80,000
```

The difference between them represents prediction error.

---

# 8. Residuals

## Definition

A residual is the difference between an actual value and its predicted value.

Formula:

```text
Residual = Actual Value - Predicted Value
```

Example:

```text
Actual    = 85,000
Predicted = 80,000
```

Then:

```text
Residual = 85,000 - 80,000

Residual = 5,000
```

Residuals help us understand how far predictions are from actual observations.

---

# 9. How the Best-Fit Line Is Learned

Ordinary Least Squares Linear Regression commonly chooses coefficients by minimizing the sum of squared residuals.

Conceptually:

```text
Actual Values
      ↓
Compare With Predictions
      ↓
Calculate Residuals
      ↓
Square Residuals
      ↓
Find Coefficients That Minimize
Total Squared Error
```

This connects Linear Regression with squared-error evaluation concepts such as MSE.

---

# 10. Simple Linear Regression

## Definition

Simple Linear Regression uses one input feature to predict one continuous target.

Example:

```text
Study Hours
     ↓
Marks
```

Here:

```text
X = Study Hours
y = Marks
```

The model can be represented as:

```text
y = mx + b
```

---

# 11. Multiple Linear Regression

## Definition

Multiple Linear Regression uses more than one input feature to predict a continuous target.

Example:

```text
House Area ───────┐
Bedrooms ─────────┤
House Age ────────┼→ House Price
Location Score ───┘
```

The general equation is:

```text
y = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ
```

Where:

```text
y  = Predicted target
b₀ = Intercept
b₁, b₂... = Coefficients
x₁, x₂... = Input features
```

Each coefficient represents the estimated relationship between its feature and the target while the other included features are held constant.

---

# 12. Simple vs Multiple Linear Regression

| Simple Linear Regression | Multiple Linear Regression |
|---|---|
| One input feature | Multiple input features |
| One `x` variable | Multiple `x` variables |
| `y = mx + b` | `y = b₀ + b₁x₁ + b₂x₂ + ...` |
| Example: Hours → Marks | Example: Area + Bedrooms → Price |

---

# 13. Positive Relationship

A positive relationship means that as the input increases, the predicted target also increases.

Example:

```text
Experience ↑
Salary ↑
```

This usually corresponds to a positive coefficient.

---

# 14. Negative Relationship

A negative relationship means that as the input increases, the predicted target decreases.

Example:

```text
Car Age ↑
Resale Price ↓
```

This usually corresponds to a negative coefficient.

---

# 15. Linear Regression Assumptions

Linear Regression is based on several important assumptions.

## Linearity

The relationship between predictors and the expected target should be reasonably representable using a linear form.

---

## Independence

Observations/errors should not have problematic dependence that violates the modeling assumptions.

---

## Homoscedasticity

The variance of residuals should remain approximately constant across fitted values.

---

## Normality of Residuals

Residuals are often assumed to be approximately normally distributed when statistical inference such as confidence intervals and hypothesis tests is required.

---

## Low Multicollinearity

In Multiple Linear Regression, input features should not have excessive linear relationships with each other.

Example:

```text
Age in Years
Age in Months
```

These features contain nearly the same information and may create high multicollinearity.

---

# 16. Evaluating Linear Regression

Common Regression evaluation metrics include:

- MAE
- MSE
- RMSE
- R² Score

## MAE

Measures average absolute prediction error.

## MSE

Measures average squared prediction error and penalizes larger errors more strongly.

## RMSE

Square root of MSE and expressed in the original target unit.

## R²

Measures model performance relative to a mean-based baseline in terms of explained target variation.

---

# 17. Advantages

- Simple to understand
- Easy to implement
- Fast to train
- Produces interpretable coefficients
- Useful as a baseline Regression model
- Works well when relationships are reasonably linear

---

# 18. Limitations

- May perform poorly on strongly nonlinear relationships
- Can be affected by influential outliers
- Multiple Linear Regression can suffer from multicollinearity
- Extrapolation outside the observed data range can be unreliable
- Important assumptions may not hold in real datasets

---

# 19. Common Mistakes

- Using Linear Regression for a categorical target
- Assuming every relationship is linear
- Ignoring influential outliers
- Ignoring multicollinearity
- Evaluating only on training data
- Treating correlation as causation
- Interpreting every intercept literally
- Assuming a high R² automatically means the model is appropriate
- Extrapolating far outside the training-data range without caution

---

# 20. Basic Scikit-Learn Syntax

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()

model.fit(
    X_train,
    y_train
)

y_pred = model.predict(
    X_test
)
```

After training:

```python
model.coef_
```

returns the learned coefficient or coefficients.

```python
model.intercept_
```

returns the learned intercept.

# Key Points

- Linear Regression is a Supervised Learning algorithm.
- It predicts continuous numerical values.
- It learns a linear relationship between features and the target.
- A best-fit line minimizes overall squared residual error in ordinary least squares.
- `y = mx + b` represents Simple Linear Regression.
- The coefficient describes the estimated change in prediction associated with a feature.
- The intercept is the predicted target when input features are zero.
- Residual = Actual - Predicted.
- Simple Linear Regression uses one input feature.
- Multiple Linear Regression uses multiple input features.
- Regression metrics can be used to evaluate model performance.
- Model assumptions and real-world context should be checked.
